# BorzMarket v9.1

Бот готовит карточки и подборки для Telegram из ссылок на Ozon и Wildberries.
Одна ссылка создаёт карточку. Две–шесть ссылок в одном сообщении создают
нумерованный коллаж со ссылками и ценами товаров.

## Изменения v9.1

- Фото можно отправить с подписью в две строки. На первой укажите `ozon:1526882900`, на второй — `Термос — 1 299 ₽`. Явные артикулы WB распознаются так же.
- Для числа без названия площадки бот даёт выбрать WB или Ozon при создании черновика, добавлении позиции в открытую подборку и в команде `/diag`. После отмены добавления старые кнопки выбора перестают действовать.
- Ссылки с протоколом, без протокола, скрытые за текстом и отдельные строки с артикулами сохраняют порядок в сообщении.
- WBCON запоминает успешную цену WB или полную карточку Ozon на 5 минут. Пока запись свежая, повторное открытие товара использует её даже во время ограничения запросов. В диагностике виден возраст ответа. Кэш хранится в памяти процесса.
- После раскрытия короткой ссылки в диагностике Ozon появляется строка с артикулом товара.

## Что нового в v9

**Загрузка данных**

- **Ozon: отпечаток Chrome.** Ozon проверяет отпечаток TLS и обычному `httpx` отвечает
  HTTP 403 (страница «Antibot Challenge») или зацикливает перенаправления. В v9 запросы идут
  через `curl_cffi`, который повторяет рукопожатие Chrome. Библиотека необязательна: без неё бот
  работает как раньше, а в отчёте `/diag` и в ошибке есть подсказка, как её поставить.
  Прежний заголовок `User-Agent: BorzMarket/8.0` убран: с настоящим рукопожатием он выдавал бота.
- **Ozon: запасной адрес API.** Если `composer-api.bx` не отдал данных, спрашивается
  `entrypoint-api.bx`. При блокировке сессия один раз «прогревается» запросом к главной странице.
- **Артикул без ссылки.** Артикулы WB уже десятизначные и пересекаются с артикулами Ozon
  (например, 1097975275), поэтому по длине площадку не угадать. Бот присылает две кнопки:
  **Wildberries** и **Ozon**. Можно сразу написать `wb 866768707` или `ozon 1526882900`.
- **Ссылки.** Принимаются ссылки без `https://` (`ozon.ru/t/...`, `wildberries.ru/catalog/...`),
  `wildberries.ru/product?card=…` и `ozon.ru/context/detail/id/…`. Повторы одного товара в
  сообщении склеиваются.
- **WB: поиск фото.** Таблица серверов `basket-NN` у WB уходит на 1–2 номера. Теперь после
  предполагаемого сервера опрашиваются ближайшие, а один тайм-аут не отменяет поиск целиком.
  Прежний предел в 60 серверов (таблица знает 65) поднят до 90. Если крупное фото недоступно,
  скачивается средний размер того же кадра.
- **WB: цены подборки одним запросом.** WB принимает несколько артикулов через «;», поэтому
  подборка из шести товаров делает один запрос цен вместо шести.
- **WB: мёртвые адреса.** Адрес `card.wb.ru/cards/v2/detail` убран: сейчас живёт только `v4`.
  Адрес, который ответил последним, спрашивается первым.
- **Повторы и кэш.** При временной ошибке чтения страницы предусмотрен один повтор. Полная карточка основной витрины хранится три минуты. Команда `/diag` запрашивает витрину заново. Для WBCON действует отдельный пятиминутный кэш.

**Панель администратора**

- `/start` и кнопка **🏠 Меню** открывают панель со счётчиками: черновики, очередь, ближайшая
  публикация, число постов за сегодня. Под строкой ввода осталось четыре кнопки.
- Под превью первыми стоят **🚀 Опубликовать** и **🕓 Запланировать**. Товары подборки выбираются
  номерами `✏️ 1 · ✏️ 2 ⚠️`, значок ⚠️ отмечает товар с недостающими данными.
- В редакторе товара редкие действия убраны под **🛠 Ещё**: цена со скриншота, WBCON, диагностика,
  сокращение названия.
- Списки показывают статус и площадку: `🟢 🟣 Термос · 1 299 ₽`, `🟡 🔵 нужно дополнить`.
  В каждом экране есть переходы назад и в меню.
- Работает `/menu` и `/help`. Старые кнопки «История» и «Помощь» в уже открытых чатах продолжают
  работать до следующего `/start`.

**Коллажи**

- Шрифт Manrope (лицензия OFL, `fonts/OFL-Manrope.txt`) вместо DejaVu: кириллица, знак ₽ и пять
  начертаний. Без файла шрифта бот возвращается к DejaVu.
- Карточки со скруглёнными углами и мягкой тенью на тёплом фоне. Номер товара стоит значком
  на фото, скидка — коралловой плашкой, площадка — цветной меткой WB или Ozon.
- Название переносится по словам на две строки, цены в одном ряду стоят на одной линии. Условие
  цены («с Ozon Картой») не пропадает в узкой плитке, а уходит отдельной строкой.
- Одиночная карточка тоже оформлена как карточка на фоне. `IMAGE_BADGES=0` по-прежнему возвращает
  исходное фото и коллаж без цветных плашек.

**Установка Ozon-отпечатка** (рекомендуется, один раз, в Debian внутри папки бота):

```bash
.venv/bin/python -m pip install -r requirements-ozon.txt
```

Если библиотека не установилась на устройстве, бот продолжит работу на `httpx`. Выключить
отпечаток можно строкой `HTTP_IMPERSONATE=0` в `.env`.

## Если сегодня не загрузились цена, фото или название

1. Отправьте боту ссылку из приложения. Если короткая ссылка Ozon не раскрывается, скопируйте артикул из карточки и отправьте, например, `ozon 1526882900`. Если Ozon отвечает HTTP 403, проверьте в `/diag` строку «Отпечаток Chrome» и при необходимости установите `curl_cffi`.
2. Введите `/diag` вместе с той же ссылкой или нажмите **Диагностика** под неполным товаром. В отчёте видны стадии загрузки, HTTP-коды, источник суммы и результат скачивания файла. Проверка выполняется на устройстве, где запущен бот. Команда не создаёт черновик.
3. **⚡ Заполнить быстро** принимает строку `Термос 500 мл — 1 299 ₽`. Её можно отправить как подпись к фотографии. Одно число в этом режиме задаёт цену. При отправке ссылки и фотографии одним сообщением используется приложенное фото. Явная сумма из сообщения имеет приоритет перед WBCON и BHAPI. Для замены уже полученной цены витрины используйте редактор.
4. **Цена со скриншота** читает изображение локально и предлагает суммы. Обрежьте скриншот до блока цен, оставьте знак рубля и выберите обычную цену. Сумма записывается только после нажатия. Фото самого товара остаётся в карточке. Для этой функции один раз выполните в Debian `apt install -y tesseract-ocr tesseract-ocr-rus`.
5. Можно отправить **файл сохранённой страницы** `.html` в UTF-8 до 8 МБ. Если в нём нет канонической ссылки, в подписи укажите прямую ссылку или `ozon:АРТИКУЛ` / `wb:АРТИКУЛ`. Бот сверяет артикул, берёт поля из файла и пробует скачать фото с площадки. Время и цена соответствуют сохранённой странице. HTML открывается как черновик для проверки.

### Резервные источники

Для WB и Ozon демо WBCON включено при подходящем артикуле. Для отключения используйте `WB_PRICE_FALLBACK=0` или `OZON_PRICE_FALLBACK=0`. Переменные управляют только автоматическими запросами к WBCON. Квота демо ограничена. После HTTP 429 бот выдерживает паузу для этого сервиса.

Владельцы ключей BHAPI могут добавить в **свой** `.env` строку `BHAPI_OZON_TOKEN=ваш_ключ` или `BHAPI_WB_TOKEN=ваш_ключ` и перезапустить бота. При неполной карточке бот сможет запросить данные по артикулу. Импорт, повтор загрузки и `/diag` могут расходовать квоту. Фоновые проверки цен обходятся без BHAPI. Услуга необязательна. Форматы ответов описаны в документации [Ozon V2](https://bhapi.ru/docs/ozon/v2) и [Wildberries](https://bhapi.ru/docs/wb).

У Ozon обычная и банковская цены хранятся отдельно. Для WB бот проверяет выбранный вариант. При стандартном регионе отличающийся регион BHAPI явно подписан в черновике. Для нестандартного `WB_DEST` регион ответа должен совпасть. Сумма из датированной истории WB служит справкой при ручной проверке. Данные резерва открываются в черновике, в том числе при включённом автопостинге.

### Оформление

Одиночное фото получает подпись с названием и ценой. У подтверждённой скидки появляется плашка. В подборке номер под фото соответствует кнопке перехода под постом. Нажатие 🔥 сохраняет кнопки покупки. Чтобы оставить оригинальное одиночное фото и убрать цветные плашки коллажа, добавьте `IMAGE_BADGES=0` в `.env` и перезапустите бота.

## Парсер цен без Telegram

Распакуйте архив, откройте терминал в папке `shopbot`. Для отдельного парсера достаточно Python 3.10+ и двух библиотек.

```bash
python -m pip install "httpx[socks]>=0.27,<1" "python-dotenv>=1,<2"
python prices.py "https://ozon.ru/t/EBIhF3Z"
python prices.py wb:866768707 ozon:1526882900 --json
python prices.py "https://www.wildberries.ru/catalog/14671602/detail.aspx?size=123" --direct-only
```

В последней команде замените ссылку на скопированную в WB после выбора размера. Значение `size` — числовой ID варианта.

- `--direct-only` обращается только к площадке. По умолчанию парсер может дополнить поля через WBCON и, при заданном ключе, BHAPI. Несколько артикулов одного запуска объединяются в группы до пяти. Для выбранного размера и нестандартного `WB_DEST` подстановка общей цены отключена.
- `--json` выводит массив в порядке ввода. Суммы передаются десятичными строками в рублях. `price` содержит выбранную сумму, `old_price` — зачёркнутую, `conditional_price` и `conditional_note` — цену и условие оплаты из виджета Ozon. Если у карточки есть только условная цена, условие также записывается в `price_note`.
- `source` указывает источник суммы. `checked_at` — время разбора в UTC. `requested_wb_dest` — регион запроса к WB. У WBCON сумма общая для артикула, без подтверждения конкретного ПВЗ.
- `status=unknown` означает, что текущую сумму получить не удалось. При явной отметке площадки об отсутствии товара возвращается `unavailable`; при ошибке ввода — `error`. В этих случаях `price` равно `null`. Историческая справка при наличии попадает только в `message`. Код завершения 0 означает, что получены цены всех переданных товаров, 1 — что остались пропуски.
- Сохранённую страницу в UTF-8 можно разобрать локально командой `python prices.py ozon:1526882900 --html card.html --json`. HTML должен содержать артикул или каноническую ссылку и данные товара. Результат имеет режим `saved_html` и отражает содержимое файла на момент его сохранения. Этот режим не обращается в сеть.

## Быстрый старт с черновиком

1. Отправьте боту ссылку или артикул. Артикул без пометки бот уточняет кнопками
   «Wildberries» и «Ozon». Сразу выбрать площадку можно записью `wb 866768707` или
   `ozon 1526882900`.
2. Нажмите **＋ Добавить товары**, чтобы превратить карточку в подборку или добавить ещё ссылки.
   Всего помещается шесть товаров. Порядок можно поменять в редакторе отдельного товара.
3. Нажмите **Цены списком**, чтобы изменить сразу несколько цен. Запись `1 = 1299,90`
   задаёт цену первого товара. Следующую цену введите с новой строки. Если в какой-то
   строке ошибка, бот укажет её номер и попросит повторить ввод.
4. В **Оформлении поста** можно выбрать другой макет для трёх, пяти или шести товаров.
   В подборке из трёх товаров по умолчанию первый получает большое фото слева.
   Альтернатива — три равноправные колонки. Плитки учитывают пропорции снимков и
   показывают фотографию целиком. Выбор макета сохраняется в черновике и в очереди.
5. Если пустует цена WB или не хватает названия, фото или цены Ozon, откройте товар
   и нажмите **Проверить через WBCON**. Бот передаст публичный артикул демо-сервису
   и заполнит доступные пустые поля. Внесённая таким способом цена получает подпись
   «по данным WBCON». Цены аккаунта, банка, выбранного размера или конкретного ПВЗ
   могут отличаться. При нулевой цене или лимите сервиса можно ввести сумму вручную.
   Для WB кнопка доступна при стандартном регионе и ссылке без выбранного размера.

## Получение данных

- Основной источник суммы — сама площадка. Если цена WB недоступна, бот может передать артикул в [WBCON](https://prices.wbcon.su/docs). Значение `WB_PRICE_FALLBACK=0` в `.env` отключает автоматический резерв при импорте и мониторинге. Кнопка ручной проверки доступна для подходящих карточек. Для Ozon действует отдельный переключатель OZON_PRICE_FALLBACK.
- Одиночная карточка с ценой из автоматического резерва открывается в черновике даже при `AUTO_POST=1`. Цена из WBCON сопровождается пометкой источника.
- Для массовых проверок у [parser.market](https://parser.market/dokumentacziya/)
  есть отдельный API заданий по ссылкам на обе площадки. В эту версию он не подключён.
- Под готовым черновиком первыми стоят **Опубликовать** и **Запланировать**.
  У незаполненного видны недостающие поля. **Загрузить недостающее** повторяет
  запрос и сохраняет ручные правки.
- Ozon раскрывает короткую ссылку до артикула, читает виджеты и структурированные
  данные карточки. Если часть полей пропущена, проверяет страницу товара.
  В редакторе товара видна отдельная банковская цена с подписью площадки, если она отличается от основной. Сумма из общей разметки
  имеет пометку «цена в карточке».
- WB ищет цену в данных товара и его размеров и продолжает поиск после
  неполного ответа. Параметр `WB_DEST` задаёт регион, по умолчанию Москва.
  Для ссылки с `?size=…` используется цена соответствующего размера. Для карточки с разными ценами бот отмечает минимальную среди доступных вариантов. При отсутствии сведений об остатках пометка ограничивается вариантами с указанной ценой.
  Фото и название загружаются отдельно. Когда WB скрывает текущую цену,
  в сообщении может появиться последняя цена из истории с датой. Поле цены
  остаётся пустым, до получения текущей суммы или ручного ввода.
- Для одиночной карточки можно прислать фото с подписью из трёх строк.
  В первой строке ссылка, во второй `Название: Термос 500 мл`, в третьей
  `Цена: 1 299 ₽`. Такой же текст работает и без фото. Если приложение
  поделилось названием и ссылкой на следующей строке, бот может взять название
  из сообщения. Внешнюю резервную цену можно уточнить прямо в сообщении, а собственное фото выбирается обложкой. Если бот использовал
  их, готовая карточка откроется для проверки даже при `AUTO_POST=1`.

При пропуске суммы с витрины можно переслать одну ссылку и скопированные строки
`Без WB Кошелька: 1 290 ₽` и `С WB Кошельком: 1 190 ₽`. Из них бот выберет
1 290 ₽ и покажет условную сумму в редакторе. Для Ozon поддерживаются пары
«С другими банками» и «С банками». Цена из сообщения открывается в черновике.

## Работа администратора

После /start под строкой ввода доступны Черновики, Очередь, Статистика и Меню. В Меню собраны История, Диагностика и Помощь.

- Пришлите артикул числом (бот спросит площадку), `wb 12345678`, `ozon 1526882900` или команды
  `/wb 12345678`, `/ozon 1526882900`. Команды удобны, если открыт режим ввода цены.
- Под черновиком можно поменять заголовок, выбрать товар, исправить его название,
  цену или фото. **Галерея** переключает изображения из витрины. Для черновиков
  v3 кнопка **Найти фото** запрашивает галерею заново.
- Кнопки **Раньше**, **Позже** и **Убрать** меняют состав коллажа.
  **Ещё → Сократить название** удаляет повторы и хвост из ключевых слов по правилам.
- **Комментарий**, **Рубрики** и **erid** дополняют подпись к посту. Комментарий
  ограничен 120 символами. Знак «-» очищает комментарий или erid.
- Кнопка **Отмена** и команда `/cancel` отменяют ввод. Новая ссылка на товар
  закрывает старый режим ввода и открывает новый черновик.
- Для публикации и постановки в очередь нужны название, цена и фото каждого
  товара. В случае недоступности витрины эти поля можно заполнить вручную.
- `/drafts` открывает черновики. В `/queue` можно перенести публикацию, отправить
  её сразу или вернуть в черновики. **В ближайший слот** выбирает свободное
  время для канала. По умолчанию это 10:00, 13:00, 16:00 и 19:00 по Москве.
  Настройка `QUEUE_SLOTS` меняет сетку. Также можно ввести дату и время по Москве
  в формате `ДД.ММ.ГГГГ ЧЧ:ММ`.

После подтверждения Telegram запись остаётся в истории с ценами, датой и ссылкой
на пост. История пополняется новыми публикациями. Когда товар уже публиковался,
бот показывает прошлую цену и ссылку на пост, а `AUTO_POST=1` оставляет такую
карточку в черновиках для проверки. Администратор может отправить её вручную.

## Цены, история и отчёты

`/history` показывает последние публикации. `/stats` показывает отчёт за 24 часа,
7 или 30 дней. В отчёте есть число карточек и подборок, число товаров каждой
площадки, средняя цена опубликованного товара, средняя скидка по товарам с двумя
ценами, реакции и результаты запросов к витринам. Учитываются проверки цен.
Кнопка 🔥 под постом даёт одну реакцию на человека. Повторное нажатие снимает её.

Бот проверяет опубликованные товары примерно раз в сутки, пока запущен. При
снижении на 15% он присылает черновик. Сравниваются цены того же варианта товара
с теми же условиями оплаты. После уведомления отсчёт идёт от новой цены, чтобы
повторная проверка той же скидки не создала новый черновик. Настройки
`PRICE_MONITOR=0` и `PRICE_DROP_PERCENT` отключают проверки или меняют порог.

### Партнёрские параметры и переходы

Укажите параметры из кабинета партнёрской программы в `WB_AFFILIATE_PARAMS`
и `OZON_AFFILIATE_PARAMS` как строку запроса, например `ref=your_code&campaign=sale`.
Бот добавляет их к ссылке товара и сохраняет выбранный размер WB. Готовый erid
вводится под черновиком. Он показывается в подписи и добавляется в ссылку.

Для подсчёта переходов задайте `CLICK_BASE_URL` как публичный HTTPS-адрес без пути.
Встроенный HTTP-сервер по умолчанию слушает `127.0.0.1:8088` на устройстве с
ботом. Направьте путь `/go/` этого адреса на сервер бота через HTTPS-прокси.
При пустом `CLICK_BASE_URL` в публикациях используются прямые ссылки.
Держите публичный путь доступным, пока в канале есть посты со счётчиком.

При подключении счётчика в `/stats` появляются переходы, топ-5 товаров и час по
Москве с наибольшим средним числом переходов на пост среди часов с двумя или
более постами. Повторные открытия учитываются. IP-адреса и данные браузеров
счётчик в SQLite не сохраняет. Для отношения переходов к просмотрам укажите
счётчик Telegram командой `/views 42 1200`. Число 42 — номер поста из `/history`,
1200 — число просмотров. Можно также вставить ссылку на пост вместо номера.

## Обновление в Termux и Debian

Скачайте `borzmarket_bot_v9_1.zip` в «Загрузки». В новой сессии Termux со строкой `~ $` выполните:

```bash
termux-wake-lock
proot-distro copy ~/storage/downloads/borzmarket_bot_v9_1.zip shopbot-debian:/root/borzmarket_bot_v9_1.zip
```

В сессии Debian, где запущен старый бот, нажмите **Ctrl+C**. Блок ниже выполняется из каталога работающей версии, рядом с её `bot.py` и `.env`. Если сессия уже закрыта, войдите через `proot-distro login shopbot-debian`. Команда `find /root -maxdepth 4 -type f -name bot.py` покажет установленные копии. Перейдите командой `cd` в каталог той копии, которой пользовались последней.

```bash
(
  set -e
  old_bot="$PWD"
  test -f bot.py && test -f .env || { echo "Перейдите в папку прежнего бота с bot.py и .env"; exit 1; }
  unzip -n ~/borzmarket_bot_v9_1.zip -d ~/borzmarket-v9-1
  cd ~/borzmarket-v9-1/shopbot
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python migrate.py "$old_bot"
  env -u ADMIN_IDS .venv/bin/python bot.py
)
```

Для последующих запусков в Debian:

```bash
cd ~/borzmarket-v9-1/shopbot && env -u ADMIN_IDS .venv/bin/python bot.py
```

При первом переносе копируются настройки и существующая база SQLite с черновиками, фото, историей и очередью. Повторный запуск переноса сохраняет уже существующие файлы в каталоге v9.1. Дополнительные зависимости при отдельном новом окружении устанавливаются отдельно.

Очередь и проверки цен работают, пока бот запущен. После остановки записи
из очереди, время которых прошло, обрабатываются при следующем запуске.
`termux-wake-lock` удерживает процессор активным при выключенном экране.
Android всё ещё может выгрузить приложение. После остановки можно снять
блокировку через `termux-wake-unlock` в Termux.

## Первый запуск

Нужен Python 3.10+. Создайте бота через [BotFather](https://t.me/BotFather) и
добавьте его в канал администратором с правом публикации.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp -n .env.example .env
```

В `.env` заполните `BOT_TOKEN`, `ADMIN_IDS` и `CHANNEL_ID`. Введите `ADMIN_IDS=0`,
если пока нужно узнать свой ID через `/id`. Затем подставьте полученный номер и
перезапустите бота. Для работы с черновиками и очередью оставьте `AUTO_POST=0`.

```bash
.venv/bin/python bot.py
```
